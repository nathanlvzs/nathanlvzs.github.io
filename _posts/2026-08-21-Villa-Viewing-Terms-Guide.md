中介话术 → 真实含义 → 你要问的问题。看房时把最后一列的问题问清，基本能避开大部分坑。

## 建筑形态（房子长啥样、私密性如何）

<div class="villa-terms-table" markdown="1">

| 中介话术 | 真实含义 | 你要问的问题 |
| --- | --- | --- |
| 独栋 | 独立一栋，四面不挨邻居，独门独院。采光、私密、院落都最好，也是最贵、最正统的一种。 | 四面是否都与邻居不共墙？花园是独占还是公共？产证房屋类型写的是“独栋”吗？ |
| 联排 | 多户并排连山墙，有自己的小院和车位，但侧面没窗、采光受限，单价相对低。 | 侧面是否有窗？实地采光怎么样？院子和车位是否独占？ |
| 双拼 | 两户拼在一起，比联排多一面采光，介于独栋和联排之间。 | 共墙那面能否开窗？隔音怎么做？与真独栋价差多少？ |
| 叠拼 | 上下两户（或上中下）叠在一起，上叠带露台、下叠带院子。总价低但密度高，更像“复式 + 院子”。 | 上叠／下叠分别送什么？得房率和公摊多少？有没有独立出入口？ |
| 合院 | 围绕一个院子布置（常走中式），几户共享中心庭院，强调围合感。 | 中庭是否独享？几户共享？院墙边界以哪里为界？ |
| 类独栋 | 本质联排／双拼，把楼间距拉大到“看起来像独栋”。不是真独栋，二手流动性和溢价都不如独栋。 | 产证房屋类型到底是“独栋”还是“联排／双拼”？侧面是否仍与邻居相连？ |
| 空中别墅 | 高层／超高层顶部的复式大平层带露台。本质是公寓不是别墅，产权、税费按住宅或商办走。 | 土地性质是住宅还是商办？落户、水电气、税费分别怎么算？ |

</div>

## 产权与交易（钱和证，最容易踩雷）

<div class="villa-terms-table" markdown="1">

| 中介话术 | 真实含义 | 你要问的问题 |
| --- | --- | --- |
| 70 年大产权 | 住宅用地，可落户、民水民电、交易正常。买别墅第一件事就是确认土地性质。 | 土地性质是住宅吗？产证是否齐全、有无抵押查封？ |
| 小产权 | 建在集体土地（村产、乡产），没有国家房产证，不能合法上市交易，风险极高。 | 有没有正规不动产权证？能不能贷款、能不能过户？ |
| 不限购 | 若建在商业／办公用地（40／50 年），不限购但水电商办标准、不能落户、税费高。“不限购”≠随便买。 | 土地性质到底是住宅还是商办？落户和税费到底怎么算？ |
| 满五唯一 | 房子满 5 年且是卖家唯一住房，可免个税，买家税费更低。 | 是否满五年？卖家家庭名下是否唯一住房？ |
| 更名／改合同 | 一手房还没出证时，开发商直接把合同名改成你的，避开过户。可能涉及违规、无法贷款、产证难办。 | 能签正规网签合同吗？能不能贷款？产证何时能办下来？ |
| 毛坯／精装／豪装 | 毛坯 = 空壳自装；精装 = 基础装修；豪装往往溢价高、风格未必合用。 | 装修报价含在总价里多少？豪装部分能否折抵砍价？ |

</div>

## 空间户型（住着舒不舒服）

<div class="villa-terms-table" markdown="1">

| 中介话术 | 真实含义 | 你要问的问题 |
| --- | --- | --- |
| 挑空 | 客厅或门厅层高做到两层（约 6 米），气派，但二楼会少一间房。 | 挑空是否可以封成房间？实用面积怎么算？ |
| 南北通透 | 南、北都有窗，穿堂风好、采光匀，是常见卖点。 | 实地南北窗都打开时，是否真的通风？ |
| 动静分区 | 活动区（客厅、餐厅）和休息区（卧室）分开，互不干扰。 | 卧室是否远离客厅、电梯和马路？ |
| 干湿分离 | 卫浴、厨房（湿区）与起居（干区）分开，或卫浴内淋浴／如厕分开。 | 几个卫生间？是否都做到干湿分离？ |
| 套房／主卧套间 | 卧室带独立卫生间，主卧套间还多带衣帽间，私密性好。 | 几间是套房？主卧套间含不含衣帽间？ |
| 地下室 | 别墅常带（半地下／全地下），可做影音、储藏。常潮湿，是否计容、是否合规要确认。 | 是否计入建筑面积？层高多少？防潮怎么做？有没有渗水痕迹？ |

</div>

## 户外与园林（环境值不值钱）

<div class="villa-terms-table" markdown="1">

| 中介话术 | 真实含义 | 你要问的问题 |
| --- | --- | --- |
| 花园面积／占地面积 | 花园是你独享的院子；占地面积是整栋（含院子）占的土地。中介常把“花园面积”往大里说。 | 花园是独占产权还是公共绿地？实测有多大？ |
| 容积率 | 小区总建筑面积／用地面积，越低越舒服（独栋区常小于 0.5）。低容积率 = 楼少、间距大、私密好。 | 小区容积率多少？独栋区容积率是多少？ |
| 绿化率 | 绿化覆盖比例，听听就好，不如直接看实际植被和楼间距。 | 实际植被密度如何？楼间距多少？ |
| 楼间距 | 前后楼距离，影响采光和低层隐私。 | 楼间距多少米？低层冬天日照有几小时？ |
| 私家泳池／温泉 | 高端配置，但问清维护成本和是否合规（有些属违建）。 | 是否合规有审批？每年维护成本多少？ |
| 前庭后院 | 前院迎客、后院私享，中式合院常见。 | 前后院是否都独享？面积各多少？ |

</div>

## 档次卖点（溢价的形容词）

<div class="villa-terms-table" markdown="1">

| 中介话术 | 真实含义 | 你要问的问题 |
| --- | --- | --- |
| 稀缺／绝版 | “城市别墅卖一套少一套”。核心区别墅用地确实稀缺，但也要看具体板块是不是真稀缺。 | 这个板块土地真的不再供应吗？周边还有没有新盘？ |
| 现房／准现房／期房 | 现房 = 已建成即住；准现房 = 快建好；期房 = 图纸买，有烂尾风险。别墅多为低密大盘，期房更要查开发商。 | 是现房还是期房？开发商资金情况和交房风险？ |
| 人车分流 | 车走地下，地面无车，安全安静，别墅区基本是标配。 | 是否真分流？访客车停在哪里？ |
| 低密 | 低密度，和“容积率”是一回事。 | 容积率具体是多少？ |
| 新中式／法式／意式 | 建筑风格，影响外观和造价，也看你喜不喜欢。 | 外立面和维护成本？物业对风格管不管？ |
| 会所 | 小区配套（泳池、健身房、宴客厅）。看是否真运营、是否额外交费。 | 会所是否运营？是否要额外交费？ |

</div>

## 看房行话（规矩与套路）

<div class="villa-terms-table" markdown="1">

| 中介话术 | 真实含义 | 你要问的问题 |
| --- | --- | --- |
| 验资 | 看房先证明你有购买力（存款／资产证明），是高端盘筛选客群的手段，不是收费。 | 验资标准是多少？需要什么证明材料？ |
| 诚意金／意向金 | 表达购买意愿的款项。注意它 ≠ 定金——诚意金通常可退，定金签了就不能退。 | 这笔钱是“定金”还是“诚意金”？不买能全退吗？ |
| 跳价／坐地起价 | 卖家临时加价，热门别墅常见。 | 价格是否锁定写进合同？违约怎么赔？ |
| 阴阳合同 | 为避税签两份不同价格的合同，违法，风险由买家承担（被查补税 + 罚款）。 | 坚决不配合。税费由谁承担？按什么价格缴税？ |
| 惜售 | 卖家挂高价或不诚心卖，营造稀缺感。 | 房东是否真卖？底价大概多少？ |
| 笋盘 | 明显低于市场价的便宜货。中介说“笋盘”时自己先比价验证。 | 为什么便宜？和周边成交价差多少？（自己比价） |

</div>

> **一句话原则：**形态看私密、产权看性质、户型看实用、园林看真实面积、卖点看水分、行话看套路。下决心前，把 **土地性质、是否真独栋、赠送面积是否合规、税费谁承担** 这四件事问清，基本就能避开大部分坑。
